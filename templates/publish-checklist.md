# Publish Checklist

## Before Publish

- [ ] Final article completed
- [ ] Frontmatter checked
- [ ] Self-citations removed
- [ ] Citation list normalized
- [ ] Prohibited style patterns checked
- [ ] Title, description, and lead checked

## Publish

- [ ] File written to repo
- [ ] Commit created
- [ ] Push completed
- [ ] Deploy started

## Verify

- [ ] Deploy success
- [ ] Canonical URL returns 200
- [ ] Live title correct
- [ ] Live lead or first paragraph correct
- [ ] Legacy or long URL behavior checked if relevant

## Completion Note

Publishing is complete only after live verification passes.
